# **App Name**: SkyPort

## Core Features:

- City Auto-Suggestions: Provide real-time city suggestions as the user types, using a mock city list.
- Flight Search and Filtering: Filter flight results dynamically based on user inputs and selections, such as price, duration and airline.
- Booking Simulation: Simulate the booking process, storing booking data temporarily in frontend state.
- E-Ticket Generation: Automatically generate an e-ticket/boarding pass with a stylish QR code and all flight details based on the simulated booking info.
- Dynamic Booking Display: Display upcoming, completed and cancelled flights, reading the simulated booking data, using colour-coded tags for status.

## Style Guidelines:

- Primary color: Royal Blue (#0052CC) to evoke trust and stability.
- Background color: Very light Sky Blue (#E0F7FF) to provide a calming and airy feel.
- Accent color: Sunset Orange (#FF6F00) to highlight important actions and CTAs.
- Body and headline font: 'Poppins' sans-serif for a modern, geometric and precise user experience.
- Use clean and modern icons to represent flight-related actions and information.
- Employ a clear and intuitive layout to enhance usability, especially on search result pages and booking forms.
- Incorporate subtle animations for page transitions, search loaders, and button interactions to improve user engagement.
