SkyPort is a frontend-only web application for searching and booking air tickets.
It provides an intuitive UI for users to explore flights, compare fares, and proceed with booking.

🚀 Features

Flight search (source, destination, date)

Login & signup UI

Booking summary page

Clean and responsive UI

Smooth navigation across pages

🛠️ Tech Stack

HTML

CSS

JavaScript

Figma (UI/UX Design)

Git & GitHub for version control

🔔 Note: This project currently has no backend. All functionalities are UI-based.
